# obhod 0.2.1 — исправление MTProto для Telegram Desktop

- Исправлена ошибка «Telegram Desktop version doesn't support this proxy type» для MTProto-ссылок.
- Неполные `ee`-секреты без домена больше не предлагаются свежему Telegram Desktop.
- Длинные hex-секреты с TLS-доменом сохраняются без ошибочного base64-декодирования.
- Проверка секретов приведена к актуальным правилам Telegram: обычный, `dd` и `ee` + домен.
- Добавлены регрессионные тесты для всех поддерживаемых форматов MTProto.
- Обновление доступно через встроенную проверку обновлений и из Assets ниже.
