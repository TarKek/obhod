# obhod 0.2.0 — Network Control Center

- Главный экран стал центром управления: состояние компонентов, профили, серверы.
- Профили Minimal / Telegram / Gaming / Browser / Full / Custom с планом изменений перед применением.
- Менеджер серверов: избранное, основной и резервный узел, ранжирование, история проверок.
- Проверка сети по этапам DNS → TCP → TLS → сервис, без ложных «работает».
- Безопасные изменения Windows: снимок DNS, резервная копия hosts, транзакции и восстановление после сбоя.
- Выключение удаляет только то, что установил obhod.
- Подписки: 14 источников, последняя рабочая версия не затирается, фиксированная ссылка `http://127.0.0.1:45871/sub`.
- Обновления компонентов и самой программы с проверкой SHA-256, резервной копией и откатом.
- Диагностический отчёт по клавише `R` с маскировкой ссылок и путей.
- Старые настройки переносятся автоматически, ничего не удаляется.
