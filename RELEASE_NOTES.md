# obhod 0.3.0 — резервный прокси Telegram

- Новый пункт «Обновить» → «Другой прокси»: если Telegram не принял лучший прокси, открывается следующий из `data\mtproto.txt`.
- Переключение идёт по кругу между тремя самыми быстрыми прокси, повторная проверка сети не нужна.
- Если списка ещё нет, пункт подсказывает сначала запустить «Прокси Telegram».
- В лог после настройки добавлена подсказка про резервный прокси.
- Порядок прокси берётся ровно тот, что записан при обновлении (быстрые сверху).
- Исправлено устаревшее упоминание в заметках: VMess в подписке уже поддерживается.
- Обновление доступно через встроенную проверку обновлений и из Assets ниже.
