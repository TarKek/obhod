# obhod

Портативный TUI для Windows 10/11 x64: бесплатный обход блокировок одним `.exe`.
Без установки, без регистрации, без телеметрии по умолчанию.

## Что умеет

| Компонент | Что делает |
|---|---|
| **zapret** | Качает релиз Flowseal, ставит службой или запускает портативно; пресет подбирается сам (ALT9 → ALT11 → ALT4 → general) |
| **MTProto** | Тянет публичные прокси, проверяет TCP-латентность с вашего IP, сохраняет топ в `data\mtproto.txt`, открывает лучший через `tg://proxy` |
| **TgWsProxy** | Находит локальный `TgWsProxy*.exe` или качает релиз, запускает и (опц.) ставит в автозагрузку |
| **hosts** | Делает бэкап; по желанию добавляет блок-лист рекламы в размеченный блок |
| **Happ / VLESS** | Качает 3 бесплатных источника, отбирает живые `vless://`, `trojan://`, `vmess://`, кладёт в `data\subs_alive_plain.txt` и готовит подписку для клиента |
| **DNS / DoH** | `1.1.1.1` + `8.8.8.8` на активном интерфейсе и DoH (Windows 11) |
| **Приложения** | Hiddify / v2rayN (портативно) или Happ (тихо), затем подписка в буфер обмена |
| **Обновления** | Отдельный пункт: проверить версии, обновить свои копии, перепроверить прокси |
| **Проверка** | YouTube, Discord, Telegram, DNS, обход — зелёным/красным |
| **Диагностика / отчёт** | Права, диск, состояние zapret, списки; анонимный отчёт в GitHub Issues |

## Быстрый старт

```powershell
cargo build --release
.\target\release\obhod.exe
```

Готовый файл: `dist\obhod.exe` (≈2.2 МБ), собирается `.\build.ps1`.

### CLI

```
obhod.exe                  # TUI, обычный режим
obhod.exe --demo           # = -m demo: всё показывается, система не меняется
obhod.exe --dev            # = -m dev: все экраны, действия реальные
obhod.exe -m normal|demo|dev
obhod.exe --demo-static    # отрисовать экраны текстом (100x30); с -m dev/normal — их вид
obhod.exe --selftest       # окружение, права, диск, что найдено
obhod.exe --check-updates  # только проверить версии программ
obhod.exe --self-update    # проверить, есть ли новая версия obhod
obhod.exe --no-update      # не проверять обновление при запуске
obhod.exe --no-elevate     # не запрашивать права администратора
obhod.exe --parse-bat "C:\zapret\general (ALT9).bat"
obhod.exe --brand          # создать brand.json и показать путь
obhod.exe --import-profile "D:\my-profile.json"
obhod.exe --version | --log-path | --open-log
```

## Как это выглядит

При первом запуске Windows спросит права администратора: они нужны для hosts,
DNS и службы обхода. Если отказаться, программа запустится в ограниченном
режиме (часть действий будет пропущена). Демо-режим и `--selftest` прав не
требуют.

Главное меню: **Включить всё** · **Выключить** · **Профили** · **Проверить** ·
**Обновить** · **Ещё** · **Выход**. Сверху — состояние и чипы компонентов
(обход, DNS, Telegram, подписки): `✓` работает, `•` частично, `✗` ошибка,
`–` выключено, `?` не проверялось.

- **Включить всё** — один экран-форма: вопросы, ответы `●/○`, на последнем
  пункте — список того, что будет включено, и явное «Ничего не устанавливается
  без вашего Enter».
- **Выключить и вернуть как было** — останавливает только ресурсы obhod, убирает
  блок рекламы из hosts, возвращает исходный DNS, снимает автозапуск. Файлы
  программы остаются.
- **Профили** — готовые наборы (минимальный, Telegram, игры, браузер, полный) и
  свои. Перед применением показывается точный список изменений; `n` — новый из
  текущих настроек, `e` — изменить, `x` — экспорт, `i` — импорт из
  `data\profiles\import.json`.
- **Проверить** — не только «сайт открылся», а этапы: DNS → TCP → TLS →
  протокол прокси → прокси → целевые сайты. Видно, где именно рвётся.
- **Ещё** — состояние сети, компоненты, история действий, диагностика, настройки
  (в `-m dev` ещё и пошаговый мастер).

Технические слова (DPI, MTProto, DoH, VLESS) — только в `-m dev`.
В прогрессе вместо лога человеческая фраза; `L` — подробный лог.

## Управление

- `↑/↓` — навигация, `Enter` — открыть/далее, `Esc` — назад, `q` — выход.
- «Включить всё»: `↑/↓` — вопрос, `←/→`/`Space` — ответ, `Enter` — следующий
  вопрос (на «Готово — включить?» запускает настройку).
- «Уже установлено»: `←/→`/`Space` — оставить как есть / настроить заново.
- «Компоненты»: `Space` — вкл/выкл.
- Текстовые поля — обычный ввод.
- В прогрессе `L` — показать/скрыть технический лог.

## Подписка и конфиги для клиентов

obhod оставляет в списке **по 2 самых быстрых сервера с каждой страны** и
переименовывает их в одном стиле: `🇩🇪 Германия | obhod`. Страны определяются
по IP через открытый ip-api (если сервис недоступен — остаются все живые узлы
без потери). Вид названия и сам бренд настраиваются в `brand.json` (см. «Бренд»).

После установки клиента (Happ, Hiddify, v2rayN) obhod готовит конфиги и
показывает инструкцию прямо в интерфейсе и в логе:

1. ссылка на подписку уже скопирована в буфер обмена;
2. откройте приложение → «Добавить подписку»;
3. вставьте ссылку (Ctrl+V) → «Добавить»;
4. серверы появятся списком «🇩🇪 Германия | obhod».

Файлы:

- `data\subs_alive_plain.txt` — отобранные узлы, по одному на строку;
- `data\subscription.txt` — то же для локального сервера подписки;
- `data\import\obhod_<клиент>.txt` — готовый файл для ручного импорта;
- `data\import\obhod_base64.txt` — он же в base64;
- `data\import\README.txt` — короткая инструкция.

Пока `obhod.exe` запущен, работает `http://127.0.0.1:<порт>/sub` (base64;
`/sub.txt` — обычный текст). Ссылка живёт, пока окно obhod открыто; после
закрытия используйте файлы из `data\import\`. Telegram-прокси (`tg://`) в
VPN-подписку не попадают — это другой протокол.

## Защита от перезаписи

Перед настройкой сканируются zapret (служба, процесс, `ImagePath`, `C:\zapret`),
TgWsProxy (рабочий стол, загрузки, `Programs`, рядом с exe), Hiddify/v2rayN/Happ
(реестр, типовые папки) и Telegram. По умолчанию всё «оставить как есть»;
перезапись — только по ручному переключению.

## Бренд

Всё оформление — в одном файле `brand.json` рядом с exe. Он создаётся при первом
запуске (или по `obhod.exe --brand`), а открыть его можно вручную — файл лежит
рядом с exe. После правки перезапустите программу.

```json
{
  "name": "obhod",
  "tagline_ru": "интернет без блокировок — просто и бесплатно",
  "tagline_en": "internet without blocks - simple and free",
  "server_name": "{flag} {country} | {name}",
  "server_name_no_country": "{flag} | {name}",
  "colors": {
    "accent": "cyan", "on_accent": "black",
    "ok": "green", "warn": "yellow", "err": "red",
    "muted": "darkgray", "secondary": "gray", "text": "white"
  }
}
```

- `name` — заголовок окна, приветствие, название подписки, имена файлов импорта.
- `server_name` — как называются серверы; подстановки `{flag}`, `{country}`,
  `{code}`, `{name}`. `server_name_no_country` — когда страна не определилась.
- `colors` — имя (`cyan`, `darkgray`, `lightblue`…), `#RRGGBB` или номер
  палитры `0`–`255`. `accent` — главный цвет, `on_accent` — текст на нём.
- Неизвестные/отсутствующие поля берутся по умолчанию, так что можно оставить
  только то, что нужно поменять.

## Портативность и данные

```
obhod.exe
obhod.json          # настройки
brand.json          # название, подпись, вид серверов, цвета
data\
  downloads\ zapret\ tgws\
  mtproto.txt  subs_alive_plain.txt  subscription.txt
  profiles.json  profiles\  history.jsonl
  hosts.backup-<ts>  report.txt  journal\  obhod.log
```

Удаление папки убирает всё, кроме службы и автозагрузки (их снимает сам
инструмент при повторной настройке либо вручную).

Права администратора нужны только для службы zapret, `hosts` и DNS.

## Логи

Всё пишется в `data\obhod.log` (ротация на 2 МБ, старый — `obhod.log.1`):
запуск, клавиши, переходы по экранам, сообщения модулей, результаты.

## Обновления

**Сама программа** обновляется при каждом запуске: TUI спрашивает GitHub о
последнем релизе, и если он новее — скачивает `obhod.exe`, подменяет файл и
перезапускается. Без сети или при ошибке просто продолжает работу. Отключить:
`--no-update`; проверить вручную: `--self-update`. Релизы — в
[github.com/TarKek/obhod/releases](https://github.com/TarKek/obhod/releases)
(обновление работает и когда папка с exe переименована или перенесена).

Пункт меню **«Обновить»** — три простых действия:

- **Обновить прокси Telegram** — перепроверить список и открыть лучший в Telegram;
- **Обновить подписку в VPN-клиенте** — заново проверить бесплатные серверы и
  обновить подписку (файл в `data\import\` и локальная ссылка);
- **Обновить программы** — проверить версии и обновить свои копии.

После выполнения возвращаешься на тот же экран: сверху одна строка итога
(«✓ Готово: …» или «⚠ С ошибками …»), ниже те же кнопки и «Назад». Версии — в
`data\state.json`, дата проверки — в `obhod.json`. Пока окно открыто, работает
фоновый монитор: раз в 5 минут обновляет состояние, раз в час проверяет, не пора
ли обновить подписки. Отдельного трея и службы-планировщика пока нет: закрытое
окно ничего не обновляет.

## Ограничения

- Публичные прокси и узлы видят метаданные (IP, время, объём); содержимое
  переписки MTProto не раскрывают. Для чувствительного — свой сервер.
- Списки устаревают: повторный запуск перепроверяет всё.
- Не «взламывает» блокировки и не гарантирует анонимность.
- Использование VPN/прокси — ответственность пользователя.
- v0.2: трея нет (`--minimized` не сворачивает), фон работает только пока окно
  открыто; ссылка на подписку живёт, пока открыт obhod (иначе — файлы в
  `data\import\`); автоматическое переключение серверов подготовлено в
  `net::manager`, но ещё не включено в UI; подписанные релизы требуют ключа в
  GitHub Secrets (без него обновление проверяется только по SHA-256 и размеру).
